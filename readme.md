## <samp>01 / ABOUT</samp>

I’m **Leonardo Scheitz**, a Software Engineering student and developer from Brazil. I like projects that demand more than a good-looking interface: things that need to **work, scale thoughtfully, and solve an actual problem**.

My day-to-day experience combines **automation, data workflows and operational systems**. Outside work, I build software, explore new technologies and turn ideas into projects that I can test, break and improve.
